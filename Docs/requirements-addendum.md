# Anexo de verificación de requisitos escolares

El archivo `Docs/requirements.md` mantiene los requisitos originales del proyecto y no debe alterarse para justificar una decisión técnica.

## Revisión requerida
El cambio de piezoeléctrico a pulsador NA modifica la adquisición de señales: ahora se detectan eventos digitales de accionamiento. Consultar a docentes si esta entrada satisface la condición de **sensor/adquisición** del trabajo. Si no la satisface, seleccionar e integrar un sensor adicional real, documentando su finalidad, circuito y datos.

## Evidencia
Conservar esquemáticos, registros de pruebas, fotografías, videos y resultados. No declarar requisitos cumplidos por el mero hecho de estar previstos en documentación.
