## Criterios

El código indica lo implementado; `testing.md` y los registros indican lo verdaderamente verificado; un simulador no reemplaza pruebas físicas. **TBD**: por definir; **TODO**: decidido pero pendiente; **IN PROGRESS**: en desarrollo; **DONE**: implementado y verificado; **BLOCKED**: dependencia externa. El MVP de entrega utiliza uno o dos nodos ESP32, aunque la arquitectura propuesta contempla cinco.
