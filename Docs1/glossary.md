# Glosario REAKT

**Gateway:** ESP32 central que coordina nodos y conecta la aplicación.

**Nodo:** módulo periférico basado en ESP32, con pulsador NA y WS2812B.

**ESP-NOW:** protocolo inalámbrico de comunicación local entre gateway y nodos.

**Pulsador NA:** contacto normalmente abierto que cierra al accionarse; produce una señal binaria.

**Antirrebote (debounce):** validación temporal para evitar que rebotes eléctricos/mecánicos se cuenten como varias pulsaciones.

**Flanco:** transición entre niveles lógicos de una entrada digital.

**WS2812B:** LED RGB direccionable utilizado para estímulos y retroalimentación.

**Modo:** actividad de memoria, agilidad, reflejos, velocidad, resistencia, precisión o coordinación.

**Evento:** registro lógico de una acción, como una pulsación válida.

**Métrica:** indicador calculado a partir de eventos observables; un pulsador no mide fuerza de impacto.

**Sesión:** entrenamiento configurado y ejecutado con uno o más nodos.

**Dashboard:** interfaz Flutter para configurar, controlar y visualizar sesiones.

**Documentación de campo:** registro escolar del proceso, pruebas y evidencias.

**ExecPlan:** plan de implementación para tareas complejas.
