# Identidad REAKT

Archivos originales entregados por el usuario el 30/10/2026:

- `reakt-symbol.png`: archivo «logo reakt», PNG RGBA de 1254×1254.
- `reakt-wordmark.png`: archivo «reakt», PNG RGB de 2048×768.

Se conservan sin modificar sus píxeles. La marca escrita se presenta con recorte
de encuadre mediante CSS/BoxFit para aprovechar el espacio de la interfaz; su
tipografía y color provienen de la imagen original, no de una fuente aproximada.

Web V1/V2: cabecera, portada, pie y favicon. Manifest: símbolo de la marca.
Flutter: copias en `app/assets/brand`, cabecera e inicio. Android: copia del símbolo
en `drawable-nodpi/reakt_launcher.png` y referencia en el manifest.

Las capturas de `assets/app` documentan la aplicación antes de este cambio; no se
retocan para simular una compilación nueva. Actualizarlas con capturas reales de
una próxima versión. Los APK ya publicados tampoco se modificaron.
